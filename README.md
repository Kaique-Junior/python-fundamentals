# Python Fundamentals

Coleção de scripts e exercícios práticos em Python focados no aprendizado de lógica de programação, algoritmos, manipulação de arquivos e estruturas de dados.

**Autor:** Kaique Junior

---

## Estrutura do Repositório

- **01_basics/**: Exercícios fundamentais cobrindo sintaxe, estruturas condicionais, laços de repetição e manipulação de dados na memória.
- **02_turtle_graphics/**: Projetos visuais e desafios práticos desenvolvidos com a biblioteca gráfica `turtle`.
- **03_unilavras/**: Exercícios e atividades acadêmicas de programação divididos por ciclos semanais da faculdade.
- **04_santander_python/**: Desafios e módulos práticos do curso Santander Open Academy, focados em manipulação de arquivos (`.txt`, `.json`) e tratamento de exceções.
