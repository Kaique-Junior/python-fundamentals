# python-fundamentals

Coleção de exercícios e pequenos scripts em Python para praticar a lógica de programação, algoritmos e sintaxe em Python.

Autor: **Kaique Junior**

## Conteúdo

- **01_basics/**: Exercícios de lógica, estruturas condicionais e gerenciamento de dados simples.
- **02_turtle_graphics/**: Exercícios visuais de manipulação de geometria utilizando a biblioteca `turtle`.

## Como executar

Para rodar qualquer um dos scripts, abra o terminal na pasta do projeto e escolha o arquivo `.py` que deseja executar.

Garanta que tenha a versão do Python atualizada.
